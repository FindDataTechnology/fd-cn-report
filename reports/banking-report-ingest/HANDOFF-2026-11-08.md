## 4. 踩过的坑（会再踩，先看这里）

**金额指标**
1. **不要回报告正文解析单位**：四种启发式（A 任意标记 / B 短表头 / C 数字就近表头 / D 按页）
   在 10 个真值样本上只做到 3–5 个正确、3–4 个错成「元」（差 10⁶）。原型已删，别再造第五个。
2. **`LIQUIDATION_RATIO` 不是流动性比例**：601398 = 108.03，而金标准是 63.20——名字像而已。
3. **`SECUCODE` 过滤返回 0 行**：F10 要用 `SECURITY_CODE`。

**假绿（本线遇到四次，全是同类）**
4. **exit 1 有两种含义**：Python 未捕获异常也是 1，而工作流把 1 当「通知失败」放行 ⇒ 崩了也报绿。
   已用 `_guarded_main()` 收敛为 **exit 2**。
5. **`--dry-run` 曾从空状态起算**：演练每次报「新增 39 条」，与真跑（0 条）不符。已改为**读状态、只不写回**。
6. **缺 DSN 会静默空转**：三个取数全跳过 → 「0 判定 / 0 事件」+ 退出码 0，与「今天平静」无法区分。
   已改为 **exit 3** 并说明。
7. **状态被回退会补发历史**：39 份处罚已入账，状态一清就重报（配了 SMTP 就是一次补发 39 封）。
   输出里现在打 `状态快照: 处罚已记账 N 份文书`——比预期小就是出事了。

**抽取与规则（B 线）**
8. **脚注句会被当大纲条目**并抢走 selector 匹配（`8、 不良贷款余额…除以…`，37 字符）→ 判据「含「。」且整行不可命中即删」。
9. **改名闸不能放宽成「不可定位就改名」**：600036 一次改 7 条，6 个锚立刻变 `nan`。
10. **`llm_section_cache` 键含段名不含文本哈希**：改大纲/选择器/note 后必须清 `.cache/reports/llm_sections/`。
11. **`rules_hash` 只覆盖 llm 规则**：删 `script_rules` 不会失效 `.cache/reports/<stem>.indicators.json`。
12. **`resolve_rule()` 每指标只取一行**：修别的行等于白修。
13. **指标名是联结键**：面板叫「**利息**净收入」，规则库叫「**净**利息收入」——按名 join 会静默丢项。
    现以规则库名为规范名，面板名放 `aliases`。

**工程**
14. **`| tail` 吞退出码**：一律 `cmd > log 2>&1; echo EXIT=$?`。
15. **「写了+测了+验收了」≠ 上产**：spiders 未入库 ⇒ ApplicationSet 看不见 ⇒ 没 CronJob ⇒ `crawl_runs` 零记录。
    查「没排期」先查 git 是否入库，别先查调度器。
16. **镜像会出但不被采用**：`image.yml` 每次推 main 都构建、cheap-3 relay 到 ccr 也正常，
    但 ApplicationSet 的 `image` 是手写死 tag，没人推它 ⇒ 集群一直跑旧片。
    用 `scripts/fd-image-bump.sh`（`--check` 当哨兵 / `--apply` 落地）；**它必须跑在能访问
    tencent 集群的机器上**（cheap3 只有自己的 `default` context）。

## 7. 仓库与并发

`fd-cn-report`、`fd-industry-data` 都是**双远端**：gitee 主开发，GitHub 跑 Actions 并自动回写
`reports/**`。非快进是常态，**不要 `git pull` 硬拉**（会把并发会话未提交的改动搅进来）。
做法：临时克隆 → `git rebase gh/main` → 推 → 删。判断是否一致要比**文件内容**，
不要用 `merge-base --is-ancestor`（rebase 后哈希变了，会误报不一致）。
